# PulseBoard — Founder’s Office Productivity Dashboard

PulseBoard is a responsive, front-end productivity dashboard concept for a Founder’s Office team. It brings task tracking and a high-level project snapshot into one simple workspace.

## Features
- Task creation with priority levels
- Update task status: To do, In progress, Completed
- Filter tasks by status
- Delete tasks and mark them complete
- Summary metrics that update automatically
- Browser localStorage persistence
- Responsive layout for mobile and desktop

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage (no backend required)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add and update tasks. Your task list is saved in that browser.

## Project scope
This is a front-end demo. Project progress cards use sample data and are not connected to a live team or backend service.
